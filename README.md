# 📄 Gerador de Lista de Pedidos

Aplicativo simples com interface gráfica feito em Python para gerar automaticamente arquivos `.txt` contendo pedidos formatados.

O usuário escolhe a quantidade de pedidos, define onde salvar o arquivo e o programa gera tudo automaticamente com barra de progresso.

---

## 🚀 Funcionalidades

- Interface gráfica simples
- Escolha da quantidade de pedidos
- Seleção do local para salvar o arquivo
- Barra de progresso visual
- Tratamento de erros
- Geração automática de pedidos numerados

---

## 🖥️ Requisitos

- Python 3.x instalado
- Tkinter (já vem por padrão no Python)
